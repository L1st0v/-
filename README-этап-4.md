# Что изменилось: четвёртый этап стал мини-игрой

Старый четвёртый этап («логово похоти») теперь пятый, его текст, кнопка
и карта не тронуты. Кодовая фраза третьего этапа тоже прежняя —
«Какие Вы умнички», она по-прежнему открывает четвёртый.

Новый четвёртый этап — аркадный автомат в мини-приложении. Кодовая фраза
для перехода на пятый: **Ком состав это тяжело**.

нет, старый `event.db` подходит.

После замены — обычный перезапуск: `python run.py`.

## Как играть

Город сверху, машина ездит по улицам. Управление — крестовина под экраном
(на телефоне пальцем, на компьютере стрелками или WASD).

1. **СКЛАД** (жёлтый) — въехали, забрали толстовки. В машину влезает 3.
2. **ПЕЧАТЬ** (синяя) — въехали, сдали сырьё. Печать идёт 8 секунд,
   за это время можно съездить за следующей партией. Приехали снова —
   забрали готовые.
3. **Зелёные дома** — там ждут толстовку. Отдали: жилец говорит
   «Спасибо!» или «Хммм, раньше мерч был лучше...», а на баланс падает
   +0 с подписью «Зато Вы комендант».

На всё 150 секунд, развезти надо 4 толстовки. Успели — экран ломается
и выдаёт слово.

## Слова

Слов четыре: `Ком`, `состав`, `это`, `тяжело`. Каждому участнику
достаётся своё — по порядку, кто раньше зашёл в бота, тот получает
первое слово, пятый участник снова первое и так по кругу. Поэтому фразу
придётся собирать всем набором вместе.

Пройденную игру приложение запоминает, так что если участник свернёт
и откроет его заново, слово покажется сразу, играть второй раз не нужно.

## Что подкрутить, если игра окажется слишком лёгкой или сложной

Всё в начале файла `web/game.js`, раздел `НАСТРОЙКИ`:

```js
const TIME_LIMIT = 150;      // сколько секунд даётся на всё
const GOAL = 4;              // сколько толстовок надо развезти
const CAR_SPEED = 108;       // скорость машины
const CAR_CAPACITY = 3;      // сколько влезает в машину
const PRINT_SECONDS = 8;     // сколько печатается одна толстовка
const SPAWN_SECONDS = 6;     // как часто на складе появляется новая
```

Слова и тексты этапов — в `content.py`, реплики жильцов — там же в
`game.js`, рядом с настройками (`HOUSE_LINES`, `REWARD_LINE`).
